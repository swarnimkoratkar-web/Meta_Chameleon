[Project Title]

Meta Chameleon

1. Team Members

   Swarnim Subash Koratkar

2. Problem Description

   Many modern mobile multiplayer games suffer from repetitive mechanics, high friction curves, and pay-to-win systems that detract from pure casual fun. Players often lack    lightweight, engaging hide-and-seek experiences that combine tactical stealth with fast-paced, intuitive interaction.

3. Project Solution

   Meta Chameleon delivers an engaging casual multiplayer hide-and-seek experience centered around dynamic camouflage mechanics. The game focuses on:

   Core camouflage mechanics allowing players to paint surfaces and blend into environments

   Engaging hide-and-seek multiplayer gameplay with intelligent bot behaviors

   Responsive touch controls optimized for quick mobile sessions

   Balanced casual fun without pay-to-win barriers

   Technologies, Frameworks & Techniques Used

4. Technology

   1) Unity Game Engine

   2) C# Scripting

   3) Techniques Implemented

   4) Dynamic Texture Painting & Color Blending Algorithms

   5) Optimized Burst-Interval Painting AI for Bot Hiders

   6) Custom State-Driven Hunter/Hider Combat & AI Behaviors

   7) Mobile Performance Optimization & Object Pooling

   8) ironSource LevelPlay Ad Mediation Integration

5. How to Run the Project Locally

   1) The project is available directly for Android mobile devices via the Google Play Store.

   2) Open the Google Play Store link on your Android device.

   3) Tap Install to download and set up the game automatically.

   4) Once the installation is complete, launch Meta Chameleon and start playing.
